# 0.1.0: first public release

**Goal:** a person signs in, connects sources, and gets data products with charts they can trust and
export, with every number traceable to an Observation. Built for the Meta AI hackathon, released so it
can be run by others.

**Status:** Released 2026-10-26 as `v0.1.0`. Unchecked boxes below carry over to 0.3.0.

## What ships

ROADMAP phases 0 to 4 are built as a working slice. 0.1.0 ships them as they stand. It adds no new
features.

| Area | In 0.1.0 |
| --- | --- |
| Sources | File timelines with lanes (CSV, JSON, images through Meta vision), screen capture, Open-Meteo weather, simulated vibration sensor, webhook ingest |
| Fusion | Asset alias matching, event-time windows, weather, vibration and inspection correlation, with provenance on every result |
| Agents | Perception, rule-based severity, Meta reasoning, claim verification. Pending alerts wait for human review. |
| Products | 6 supported: object detection dataset, density heatmap, vehicle traffic dashboard, road safety event feed, people count, attribute breakdown. 26 more are listed as roadmap. |
| Flows | Node editor and API over the same JSON, plus drafting a flow from plain words |
| Surfaces | Projects hub, engine map, replay, `/explore` sharing, CSV export, REST API keys, MCP server, admin console |
| Engineering | `bun test` on PGlite with a 95% per-file gate, GitHub Actions CI and tag-driven releases |

## Not in 0.1.0 (cut list)

Moved to 0.3.0 or later. Adding any of these unfreezes the release.

- Real RTSP or camera streams, MQTT broker, database and REST-poller connectors
- Fuzzy or embedding entity matching, PostGIS spatial joins
- Data Fusion Canvas and a product-builder UI beyond flows
- Any of the 26 roadmap products
- Multi-tenant teams and roles (0.1.0 has one owner per project, plus read-only admins)

## Known issues to note in the release

- Replay groups row arrivals by the minute, so "First rows arrived" can be timed a few seconds before
  "Project created" for a project that got data straight away. Display only.
- Scheduled polling needs the external drain trigger above. Without it, jobs run when someone uses the app.

## Risks

| Risk | Mitigation |
| --- | --- |
| Meta API cost or latency during demos | Frame sampling (tune dial), recorded fallback clip |
| LLM-made numbers | Claim verification and flow fact-check reject unlisted numbers (both tested) |
| Untested route glue | The test debt section above. Routes are thin wrappers over tested `ops` functions. |
| Next 16 instant-navigation rules | Keep data reads inside `<Suspense>` (see the `/projects` fix) |
